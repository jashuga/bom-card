# Bom-card
A fun arcade style shooter where you customize your playthrough by picking from ammo and upgrade options while battling through waves of enemies.

## Inspiration
We were inspired by classic arcade shooters and newer deckbuilding and roguelike experiences to combine fast action with deliberate strategy.

## What it does
Our project is a playable game, a fusion of classic arcade shooters and deckbuilding genres

## How we built it
We built the game entirely in Godot, using C#. VS Code was predominantly used as a code editor. Claude code was used as a reference and aid.

## Challenges we ran into
Most of the challenges we ran into were of scope and direction. For example, deciding whether the player could only shoot along one axis, and focusing on polishing the existing mechanics instead of adding more. 

## Accomplishments that we're proud of
Some of the deeper implementation details of the game's inner workings were especially fun and challenging to figure out. The deckbuilding portion meshes with the enemy waves, involving the lists of ammo and enemy types all in one system

## What we learned
This was many of our teams' first experience with Godot, and together we quickly learned to put together scenes and nodes into a game complete with UI and sound.

## What's next for Bom-card
The 24 hour time constraint necessitated that we overlook some scope in the name of making a complete product. Fleshing out the game with more ammo types and enemies will take much longer, but will give it more replayability.
